# 🚌 BusDirect — Système de réservation de places de bus

## 📌 Présentation

**BusDirect** est une application web de réservation de places de bus pour le trajet **Safi → Marrakech**. Elle permet de gérer les réservations des passagers grâce à une interface interactive et simple à utiliser.

Le projet a été réalisé dans le cadre d'un apprentissage du développement web, avec un focus particulier sur la manipulation du DOM en JavaScript et la création d'interfaces avec Tailwind CSS.

## ✨ Fonctionnalités

- 🎫 **Réservation de places** : réserver une place disponible en choisissant son numéro.
- 👤 **Gestion des passagers** : saisir le nom du passager et empêcher les réservations en double pour un même nom.
- 🪑 **Plan des places interactif** : visualiser les places libres et occupées grâce à un code couleur.
- ✏️ **Modification des réservations** : changer la place attribuée à un passager.
- 🗑️ **Suppression des réservations** : libérer une place pour permettre une nouvelle réservation.
- 📊 **Suivi en temps réel** : afficher le nombre de places disponibles et les recettes générées.
- 💾 **Sauvegarde des données** : utiliser `localStorage` pour conserver les réservations dans le navigateur après le rechargement de la page.

## 🛠️ Technologies utilisées

- **HTML5** — Structure de l'application.
- **Tailwind CSS** — Mise en forme et création d'une interface responsive.
- **JavaScript** — Manipulation du DOM, gestion des événements et logique de réservation.
- **localStorage** — Stockage local des réservations dans le navigateur.
- **Git & GitHub** — Gestion de versions et hébergement du code source.

## 🚀 Installation et utilisation

### 1. Cloner le dépôt

```bash
git clone git@github.com:Douaeaghmir/BusDirect.git
```

### 2. Accéder au projet

```bash
cd BusDirect
```

### 3. Lancer l'application

Ouvrez le fichier `index.html` dans votre navigateur.

Vous pouvez également utiliser l'extension **Live Server** de Visual Studio Code pour lancer le projet localement.

## 📖 Comment utiliser l'application ?

1. Saisir le nom du passager.
2. Choisir une place disponible.
3. Confirmer la réservation.
4. Consulter le plan des places et les statistiques.
5. Modifier ou supprimer une réservation si nécessaire.

## 🎯 Objectifs pédagogiques

Ce projet permet de pratiquer :

- La sélection et la manipulation des éléments HTML avec le DOM.
- L'utilisation de `addEventListener()` pour gérer les événements.
- La validation des formulaires.
- La manipulation des tableaux et des objets JavaScript.
- La synchronisation entre les données et l'interface utilisateur.
- L'utilisation de `localStorage` pour sauvegarder les données.
- La création d'une interface responsive avec Tailwind CSS.
